# 容量电价机制：从政策驱动到市场驱动

> 2026年1月30日，国家发改委、国家能源局印发《关于完善发电侧容量电价机制的通知》，首次在国家制度层面为电网侧独立新型储能建立容量电价补偿。机制的核心创新在于：容量电价水平与**放电时长直接挂钩**。这一变化重写了储能项目的收益结构，也让"4小时"从一个技术参数变成一门生意。

---

## 一、机制全文要点

<figure>
  <img src="/assets/img/capacity-price.svg" alt="容量电价机制按放电时长折算的收益结构">
  <figcaption>容量电价 = 当地煤电容量电价 × (满功率连续放电时长 ÷ 全年最长净负荷高峰持续时长)，折算比例最高不超过1。</figcaption>
</figure>

### 核心条款

| 要素 | 内容 |
|------|------|
| **适用对象** | 服务于电力系统安全运行、**未参与配储**的电网侧独立新型储能电站 |
| **计价基准** | 当地煤电容量电价标准 |
| **折算公式** | 满功率连续放电时长 ÷ 全年最长净负荷高峰持续时长 |
| **折算上限** | 比例最高不超过 **1** |
| **结算属性** | 各地可根据本地情况给予容量电价 |

### 一句话解读

> **纳入清单管理的独立储能电站能拿到的容量收益，第一次和能放电多少小时直接挂钩了。**

折算比例越高、容量电费越高；而放电时长越长，折算比例天然越高。这解释了为什么2026上半年4小时系统中标均价同比涨21.1%，而2小时系统只涨8.3%——多出的约12个百分点，不是电芯涨价能解释的，而是市场在给时长单独标价。

## 二、新疆算例：最清晰的落地样本

新疆发改委2026年5月发布容量电价新规，**自6月1日起执行**：

| 参数 | 取值 |
|------|------|
| 煤电容量电价基准 | **165 元/千瓦·年** |
| 全年最长净负荷高峰持续时长 | 暂定 **6 小时** |

按此公式折算：

| 项目时长 | 折算比例 | **容量电价** |
|----------|----------|--------------|
| **4 小时**独立储能 | 4/6 = 0.667 | **110 元/千瓦·年** |
| **2 小时**独立储能 | 2/6 = 0.333 | **55 元/千瓦·年** |
| 6 小时及以上 | 1.0 | 165 元/千瓦·年 |

一座100MW的4小时独立储能电站，仅容量电费一项年收入约 **1100万元**。这相当于设备投资的 2%—3%——单看比例不算惊人，但对IRR只有3%—4%的存量独立储能项目而言，这是决定性的变量。

## 三、落地进展：七省细则已出

| 时间 | 进展 |
|------|------|
| 2026年1月 | 发改委、能源局印发容量电价机制通知 |
| 2026年1月 | 首次将电网侧独立储能纳入容量电价补偿体系 |
| 2026年5月 | 新疆发布细则，6月1日执行 |
| 至2026年9月 | **甘肃、吉林、陕西、新疆、湖北、宁夏、青海** 等省相继出台实施细则 |
| 2026年9月 | 行业统计显示已有 **10+省份** 出台细则 |

**未参与配储**这一限定条件值得注意——该机制的受益主体是独立储能电站，而非作为新能源强制配套的配储项目。这一设计意图明确：用市场化机制替代行政摊派，让真正具备调节能力的资产获得报酬。

## 四、收益结构重构：从三元到四元

容量电价落地后，独立储能的收益模型由原来的两元结构升级为多元结构：

| 收益来源 | 机制依据 | 特点 |
|----------|----------|------|
| **容量电费** | 容量电价机制（2026.1） | 与放电时长挂钩，稳定、可预期 |
| **能量市场套利** | 现货市场 / 分时电价 | 峰谷价差驱动，波动最大 |
| **辅助服务** | 调频、调峰、备用 | 里程补偿+容量补偿双轨 |
| **政策补贴** | 地方专项补贴 | 不确定性最高 |

### 用户侧的三元叠加

工商业侧虽暂未直接纳入容量电价，但收益结构同样在改善：

| 收益来源 | 典型水平 |
|----------|----------|
| 峰谷价差套利 | 浙江、广东两省峰谷价差扩大至 **0.8—1.1元/kWh** |
| 需量管理 | 按变压器容量计费优化 |
| 需求响应 | 迎峰度夏期间压减高峰负荷 |

2026年迎峰度夏期间，上海、江苏、浙江、安徽、湖北、四川等省通过虚拟电厂+错峰检修，单日压减高峰负荷最高近 **177万千瓦**；用户侧储能单项目IRR回升至 **6%—8%**，优质项目突破 **10%**。

## 五、配套机制：项目库整顿

与容量电价同步推进的，是项目库的大规模整顿。收益机制不落地，就会催生"抢到指标就等于锁定未来收益"的投机行为。

| 省份 | 整顿措施 |
|------|----------|
| **河北** | 独立储能项目排查整顿专项行动：延期开工项目 **69个/990.5万千瓦**，取消建设计划项目 **16个/175万千瓦** |
| **山西** | 第五轮项目库调整单轮清退 **31个/605万千瓦/1208万千瓦时**；9月1日起入库项目须 **6个月内实质性开工、12个月内建成并网** |
| **河南** | 纳入省级清单的独立/共享储能须 **6个月内开工、15个月内并网**，逾期移出清单、不再享受容量电价支持 |

**"逾期移出清单、不再享受容量电价支持"是本轮整顿的关键约束**——它把容量电价资格与项目落地进度硬绑定，消除了"占着指标等政策"的套利空间。

### 山西样本：储备173.49GWh，落地不足15%

| 指标 | 数值 |
|------|------|
| 项目库总储备规模 | **173.49GWh** |
| 实际落地率 | **不足15%** |
| 2026年9月起新规 | 6个月开工 / 12个月并网 |

### 新疆：优选引入构网型要求

2026年9月16日，乌鲁木齐市发改委发布《关于做好2026年第二批独立新型储能项目优选工作的通知》：

| 维度 | 要求 |
|------|------|
| 规模上限 | 每个区（县）申报不超过3个，总规模不超过 **700MW** |
| 技术路线 | 重点聚焦示范引领、多元化技术路线、技术先进性、规范安全4个维度 |
| 鼓励方向 | 压缩空气、重力、热（冷）、飞轮、液流电池、氢储能等多类型技术路线 |
| 构网型 | 支持在**电网薄弱环节**探索建设一定比例的构网型储能 |

值得注意的是，在装机整体负增长的背景下，新疆仍给出700MW的独立储能申报空间，且首次把"多元技术路线"和"构网型"写入官方优选维度。

## 六、机制的产业影响

| 影响维度 | 分析 |
|----------|------|
| **时长选择** | 4小时及以上项目收益结构显著改善，可能成为新建项目主流配置 |
| **独立 vs 配储** | 独立储能资产价值上升，"未参与配储"的表述反向提高了独立储能的制度地位 |
| **投资逻辑** | 从"抢指标套利"转向"算收益建项目"，IRR 3%—4%的项目面临出清 |
| **技术路线** | 长时技术获得政策溢价，因为容量电费按放电时长线性折算 |
| **出清速度** | 6个月开工/12个月并网的时限，配合容量电价资格撤销，将显著加快洗牌 |

---

## 七、尚待解决的问题

| 问题 | 现状 |
|------|------|
| **峰值时长的地区差异** | 新疆暂定6小时，其他省份的"全年最长净负荷高峰持续时长"取值差异大，直接导致容量电价水平跨省不可比 |
| **折算上限1的紧约束** | 6小时以上项目无法获得更高容量电价，超长时长的边际激励被截断 |
| **考核与可用性** | 容量电费需与实际可用容量挂钩，考核细则尚待统一 |
| **多省细则衔接** | 已有10+省份出细则，跨省资产的收益测算口径仍不统一 |
| **配储项目的身份界定** | "未参与配储"的认定标准在地方执行中口径不一 |

---

## 八、结论

> 容量电价机制是2026年储能行业最重要的制度变化，其意义不在于补贴金额，而在于**首次让储能资产的收益与它提供的系统价值对价**。4小时电站110元/千瓦·年 vs 2小时电站55元/千瓦·年的差异，把"时长"从一个工程选择变成了一个财务决策。这解释了2026上半年4小时系统中标均价逆势上涨21.1%、8—9月采招中4小时项目持续放量、乌鲁木齐优选文件把构网型和多技术路线写入评分维度等一系列现象。随着10+省份细则落地，储能行业"十五五"期间的核心竞争将从"能否建成"转向"每度电能否卖对价"。
