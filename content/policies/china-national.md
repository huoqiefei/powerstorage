# 中国储能政策全景（2026）

> 2026年是中国储能产业政策的"大年"。新型储能首次列入国家六大新兴支柱产业，容量电价机制落地，"十五五"规划定调——政策体系趋于完善。2026年被定义为**独立新型储能市场化发展元年**。

---

## 一、"十五五"规划：战略升格

2026年3月全国两会，新型储能**首次被列入国家六大新兴支柱产业**。"十五五"规划纲要明确**"大力发展新型储能"**，标志储能从"辅助性技术"跃升为能源体系稳定运行的核心组成部分。

国家能源局明确：**新型储能将成为"十五五"电力系统新增灵活调节能力的主要载体**。

截至2025年底，中国新型储能累计装机**1.36亿kW/3.51亿kWh**，较"十三五"末增长**40倍**。2030年装机目标**3亿kW以上**。

---

## 二、国家层面关键政策

### 容量电价机制落地（里程碑）
**《关于完善发电侧容量电价机制的通知》**（114号文，2026年1月30日）：
- **首次**在国家制度层面将电网侧独立新型储能纳入发电侧容量电价机制
- 按照**"同工同酬"原则**，对标当地煤电容量电价标准，根据放电时长和顶峰能力按比例折算
- 补齐储能收益最后拼图：**容量补偿 + 电能量套利 + 辅助服务**三元收益模型成型

### 新型储能规模化建设专项行动方案（2026年5月）
- 推动"新能源+储能"作为联合报价主体一体化参与电能量市场交易
- 鼓励地方探索爬坡、转动惯量等辅助服务新品种
- 稳定储能行业发展预期

### 《新型电池产业发展"十五五"规划》（2026年9月28日，七部门联合发布）

**这是"十五五"储能领域最重要的产业政策文件**，由工业和信息化部、国家发展改革委、交通运输部、商务部、国家市场监督管理总局、国家能源局、国家铁路局七部门联合发布。

针对新型储能领域的核心要求：

| 方向 | 具体部署 |
|------|----------|
| **技术攻关** | 将研发**长寿命、高安全储能电池**作为核心技术攻关方向 |
| **场景拓展** | 部署开展新型储能在**智算中心和工业绿色微电网**等创新场景的应用探索 |
| **政策衔接** | 与"十五五"规划纲要"大力发展新型储能"总体要求形成上下衔接 |
| **产业协同** | 从产业技术标准、应用场景拓展、产业链协同多维度提供支撑 |

**两份"十五五"专项规划的量化目标：**

| 规划文件 | 目标 |
|----------|------|
| 《新型能源体系建设"十五五"规划》 | 到2030年新型储能装机达 **3亿千瓦**，比现在再翻一番；大力发展新型储能、加力发展长时储能、鼓励多种技术路线发展 |
| 《新型电力系统建设"十五五"规划》 | "十五五"新增可承担顶峰保供作用的电网侧独立储能约 **8000万千瓦**，等效顶峰时长力争达 **4小时** |

### "十五五"新型储能发展实施方案
- 组织编制**"十五五"新型电池发展规划**（已升级为七部门联合发布的《新型电池产业发展"十五五"规划》）
- 动态跟踪储能电池产能、产量、价格等关键运营指标

## 三、项目库整顿：6个月开工令（2026年9月）

政策驱动转向市场驱动的另一面，是对"圈而不建"的清理。2026年 多地出台硬性时限：

| 省份 | 整顿措施 |
|------|----------|
| **河北** | 《独立储能项目排查整顿专项行动方案》：延期开工项目 **69个/990.5万千瓦**，取消建设计划项目 **16个/175万千瓦** |
| **山西** | 第五轮项目库调整单轮清退 **31个/605万千瓦/1208万千瓦时**；项目库总储备173.49GWh但实际落地率**不足15%** |
| **山西（9月1日起）** | 入库项目须 **6个月内实质性开工、12个月内建成并网** |
| **河南** | 纳入省级清单项目须 **6个月内开工、15个月内并网**，逾期移出清单、**不再享受容量电价支持** |

配套机制方面，**新疆5月发布容量电价新规（6月1日执行）**：以煤电容量电价165元/千瓦·年为基准，全年最长净负荷高峰持续时长暂定6小时，折算出4小时独立储能容量电价 **110元/千瓦·年**、2小时 **55元/千瓦·年**。至9月，甘肃、吉林、陕西、新疆、湖北、宁夏、青海等省已相继出台细则。

**"逾期移出清单、不再享受容量电价"是本轮整顿最关键的约束**——它把容量电价资格与项目落地进度硬绑定，消除了"占着指标等政策"的套利空间。

### 各地"十五五"新型储能目标

| 地区 | 目标 |
|------|------|
| **山西** | 规划14GW新型储能装机 |

| **内蒙古** | 4300m最高海拔构网型储能（西藏）配套 |

## 七、政策趋势研判

| 趋势 | 解读 |
|------|------|
| **从"强制配储"到"市场驱动"** | 山东率先取消强配，储能回归市场价值驱动 |
| **从"规模扩张"到"质量优先"** | 安全监管趋严、标准体系完善、国标强制实施 |
| **从"单一技术"到"多元融合"** | 政策支持构网型、长时储能、钠锂混合方案 |
| **从"电力配套"到"独立主体"** | 独立储能可参与现货市场、辅助服务、容量市场 |
| **从"国内发展"到"全球竞争"** | 政策鼓励出海，抢占全球储能市场 |
| **区域分化明显** | 三北侧重长时储能促消纳，中东部侧重2h短时储能保供 |
| **"十四五"首次半年负增长** | 2026H1新增投运21.81GW/58.60GWh（同比-18%/-16%），政策供给侧整顿的结果 |
| **九部门产业规划协同** | 9月28日七部门《新型电池产业发展"十五五"规划》+ 智算中心/工业绿电新场景 |

> 2026年的政策关键词是**"完善"与"规范"**。1月容量电价机制解决了"储能如何赚钱"，9月七部门产业规划与多省项目库整顿解决了"储能如何不空转"。前者建立收益标准，后者建立准入门槛，两者共同把行业从政策驱动推向市场+政策双轮驱动。2026H1装机首次半年负增长（-18%）不应被解读为政策失效——**在装机下滑的同时，系统集采招标+95%、EPC中标+112%、海外订单+83%**，说明需求并未消失，只是从"行政摊派"转向了"价值兑现"。9月28日《新型电池产业发展"十五五"规划》把智算中心、工业绿色微电网列为新场景，与CNESA对下一阶段增长由"项目经济性、长时技术、构网型储能和AI数据中心新需求"塑造的判断完全吻合。
