# 飞轮储能与新兴技术

> 飞轮储能以毫秒级响应速度见长，是电力系统**调频**和**电能质量**保障的利器。2026年，磁悬浮飞轮技术取得突破，"飞轮+"混合储能方案加速落地。

---

## 飞轮储能

### 工作原理
- **储能**：电动机驱动飞轮高速旋转，电能→动能
- **释能**：飞轮减速驱动发电机，动能→电能
- **磁悬浮轴承**消除摩擦损耗，真空腔体减少空气阻力

### 性能特征

| 指标 | 典型值 |
|------|--------|
| **功率密度** | 500-5000 W/kg |
| **响应时间** | <5ms（毫秒级） |
| **循环寿命** | 100万次+ |
| **效率** | 85-95% |
| **自放电率** | <5%/天（磁悬浮） |

> 寿命可达**30年以上**，几乎无衰减

### "飞轮+"混合储能方案

```
飞轮（毫秒级响应）+ 锂电（分钟-小时级）+ 液流（小时级）= 全时域覆盖
```

飞轮处理**第一次扰动** → 锂电承担**分钟级调节** → 液流/铁空气提供**长期支撑**

## 热化学储能 (TCES)

### Cache Energy × 美国陆军（2026年5月）

| 指标 | 详情 |
|------|------|
| **材料** | 氧化钙基颗粒（CaO） |
| **机理** | CaO + H₂O ⇌ Ca(OH)₂ + 热 |
| **成本** | **$5-10/kWh**——比锂电便宜100倍 |
| **能量密度** | 高 |
| **可持续性** | 原料丰富、可回收、无毒 |

- 5kW原型反应堆设计完成
- 2027年财年目标：验证军事基地级解决方案
