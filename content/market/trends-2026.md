# 储能市场趋势与展望

> 2026年上半年，中国新型储能新增投运 **21.81GW/58.60GWh**，同比下降18%——"十四五"以来首次半年负增长；但系统集采招标+95%、EPC中标+112%、海外订单+83%、全球电芯出货+94.76%。这不是行业失速，而是行业从"规模扩张"切换到"价值重构"。

## 五大市场趋势

### 1. 百GW时代到来
储能年新增装机从10GW到突破100GW仅用**4年**（光伏用了8年，风电用了15年）。LFP占年新增装机的**90%**，500Ah+大容量电芯2026年有望占大储市场近15%。

### 2. 锂价反弹 + 消费税落地，电芯价格上行
- 2026年5月碳酸锂价格时隔两年**重新站上20万元/吨**，年内涨幅超67%
- **9月11日报约14.1万元/吨**；9月1日锂电池消费税正式落地，产业链进入宽幅震荡
- 314Ah电芯8月均价**0.365元/Wh**（较2025年底+18%）；**9月中标加权均价0.3814元/Wh，同比+38.3%**
- 行业从"价格战"转向"价值战"——客户最关心的是**交付周期**而非价格

### 3. 钠锂双星时代：GWh级交付落地
- 宁德时代×海博思创签署**60GWh**钠电三年长协（全球最大钠电订单）；宁德时代9月交付首批系统，全年GWh级出货
- 海辰储能9月发布 **N785Ah** 电芯（20000次循环）+ **4MWh** 系统，2027年量产
- 平价公式明确：海辰目标碳酸锂**15万元/吨**时与锂电持平（当前14.1万元/吨，已接近）
- 但任丘项目钠电中标价**1.035元/Wh**，约为锂电标段两倍——项目层面价差仍大
- 2026H1全球储能电芯出货 **467.84GWh**（同比+94.76%），InfoLink上调2026年预测至**1026GWh**

### 4. AI+储能深度融合
- AI算力基建成为储能需求新增长极，与能源转型、电网阻塞构成**三重驱动**
- 南网储能AI平台：8座试点电站故障率降34%，新能源消纳电量提升约30%
- AI预测（气象）+ AI优化（调度）+ AI诊断（运维）全链条渗透

### 5. 中国企业全球化：订单 +83%
- 2026H1中国企业海外储能订单 **298GWh**，同比 **+83%**；电芯海外出货占比**首次超过国内**
- 9月密集大单：天合×日本AMPlify约1GWh、阳光电源×马来西亚ERS1GWh、隆基×罗马尼亚50MWh、亿纬×Fluence **206GWh**（5年长协）
- 逆变器1—8月出口额 **526亿元**（+22%），对非出口+49%、8月中东+70%、印度+61%
- 从设备出口到EPC+本地制造全链条出海

### 6. 4小时系统成为新主流（9月新增）
- 2026H1 4小时系统中标均价541.3元/kWh（**+21.1%**），涨幅高出2小时系统12个百分点
- 9月第三周4小时系统均价跌至 **0.5176元/Wh**，较2025年同期（0.65元/Wh）**降幅超20%**
- 驱动因素是1月落地的容量电价机制：**4小时电站110元/千瓦·年 vs 2小时55元/千瓦·年**
- 新疆以煤电容量电价165元/千瓦·年、峰值时长6小时为基准折算，**市场首次给"时长"单独定价**

## 风险与挑战

| 风险 | 影响 |
|------|------|
| **锂价持续上涨** | 电芯9月同比涨38.3%，低价中标项目成本失控 |
| **产能过剩** | 规划总产能近2000GWh，但314Ah/587Ah/790Ah仍"一芯难求"，名义与有效产能错位 |
| **装机首降** | 2026H1新增投运同比-18%，独立储能落地率仅30%—40%、山西不足15% |
| **EPC毛利压缩** | 9月中广核呼和浩特350MW/1400MWh EPC报价低至0.564—0.565元/Wh |
| **安全事件** | 储能火灾影响公众信心和政策环境 |
| **供应链依赖** | 锂、钴、石墨地缘风险加剧 |
| **贸易壁垒** | 关税壁垒和本地化要求增加出海难度 |

## 2030展望

> 到2030年，全球储能年装机预计突破**1TWh**。储能将从"新能源的附属品"演变为电力系统的**核心基础设施**——既是电力的"蓄水池"，也是能源互联网的"路由器"，更是源网荷储一体化的"操作系统"。2036年全球累计装机预计达**2,867GW/10,514GWh**，是2025年水平的10倍。

| 关键指标 | 2030年预测 |
|---------|-----------|
| 全球年装机 | >1TWh |
| 中国累计装机（CNESA预测） | 2026年底200.7—221.9GW；2030年371.2—450.7GW |
| 中国累计装机（政策目标） | 2030年 **3亿千瓦**，比2025年底1.36亿千瓦翻一番 |
| 电网侧独立储能 | "十五五"新增约 **8000万千瓦**，等效顶峰时长力争 **4小时** |
| LDES占比 | 10-15% |
| AI渗透率 | >80% |
| 储能系统成本 | 锂价回升中，钠电补充 |
