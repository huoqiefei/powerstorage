# AIDC 储能：算力基建重塑储能需求曲线

> 2026年9月亿纬锂能与美国头部储能集成商 Fluence 签署 2027—2031年 **206GWh** 供货框架协议，其中2027年承诺交付 **16GWh**、2028—2031年预留 **190GWh**。Fluence 由西门子与 AES 合资成立，深度布局 AIDC 领域。这笔订单标志着 AI 数据中心从储能行业的"概念性增量需求"，变成了可量化的长期采购合同。

---

## 一、为什么 AIDC 是确定性的新增需求

传统储能的需求曲线由三件事决定：新能源装机、峰谷价差、电力市场规则。AIDC 引入了一个完全不同的驱动变量——**算力负荷**。

### 三类负荷特性对比

| 特征 | 新能源配套储能 | 电网侧独立储能 | **AIDC（AI 数据中心）储能** |
|------|----------------|----------------|---------------------------|
| 负荷连续性 | 间歇 | 间歇 | **7×24 连续高负载** |
| 功率密度要求 | 中 | 中 | **高（GPU 集群瞬时功率）** |
| 对电能质量敏感度 | 低 | 中 | **极高** |
| 用电成本敏感度 | 低 | 高（价差套利驱动） | **中（受 PUE 约束）** |
| 备电需求 | 低 | 低 | **高（不可中断）** |
| 支付能力 | 低（依赖机制） | 低（依赖机制） | **高（企业自有预算）** |

**关键差异在于支付能力。** 新能源配套与独立储能的收益高度依赖补贴与市场机制，项目 IRR 普遍在 3%—18% 区间；而 AIDC 储能由企业的数据中心资本开支直接支付，不依赖任何外部机制。CNESA 在展望下一阶段增长时明确把"AI 数据中心新需求"与项目经济性、长时技术、构网型并列。

## 二、Fluence 206GWh 订单的信号意义

| 要素 | 内容 |
|------|------|
| 签署方 | 亿纬动力（亿纬锂能子公司） × Fluence（西门子 + AES 合资） |
| 总量 | **206GWh** |
| 2027年承诺量 | **16GWh** |
| 2028—2031年预留 | **190GWh** |
| 买方定位 | 美国头部储能集成商，深度布局 AIDC 领域 |

### 为什么这笔订单值得单独关注

**第一，量级足够大。** 16GWh 的2027年承诺量，放在国内已是大型集采量级，单个海外集成商的年度采购承诺达到这个规模并不常见。

**第二，周期长达5年。** 储能行业长期缺乏5年期框架订单。5年预留意味着买方在做长期容量规划，而非战术性采购——这正是AIDC负荷的特征：一旦机房建成，电力配套方案不会轻易更换。

**第三，供应方从"中国出口"变成"全球配套"。** 2026年上半年中国储能电芯海外出货占比首次超过国内；同期中国企业签署海外储能订单 **298GWh**，同比增长 **83%**。Fluence 这笔订单是这个趋势的标志性案例。

## 三、AIDC 储能的技术要求

### 1. 构网型 + 分钟级黑启动

9月15日比亚迪发布的 GW级构网型储能方案 2.0 直接指向这类场景：

| 能力 | 参数 |
|------|------|
| **分钟级黑启动** | GW级储能电站支持 |
| **7×24 不间断供电** | 全方案支持 |
| 过载能力 | 3倍过载 **10秒** |
| 峰值转换效率 | **99.50%** |

"7×24小时不间断供电"正是数据中心对储能的硬性表述。传统储能不承担这一职责（由柴油发电机/UPS承担），而 AIDC 储能正在尝试把储能做成主供电的一部分。

### 2. 高功率密度与长时兼备

AIDC 的负荷特征是"高功率+中等能量"：GPU 集群瞬时功率需求大，但持续时间有限。因此 AIDC 储能倾向于 **2 小时以上、功率密度高** 的配置——这与当前 4小时项目主流化的趋势同向。比亚迪 MC CubeXT 搭载 1980Ah 储能专用刀片电池，定位正是"2小时及以上长时储能场景"。

### 3. 无损检测与质量管控

9月29日常州能博会上，江苏赛科检测发布数实融合无损检测分析技术，建成**全球首个新能源第三方无损检测超级实验室**，依托大CT设备与AI技术，**无需拆解电池包即可排查内部隐患**。这类检测能力对AIDC 场景尤其关键——数据中心停机一次的损失远高于设备本身价值。

### 4. AI 能源大模型

深度动力在同届能博会发布 **量格 EFM-70B 能源大模型**技术成果，依托物理硬约束架构，模型实现超过 **99.5% 的物理一致性**，构建 "Real-Sim-Real" 闭环运行体系，打通绿电、电网、算力全链路优化。

物理一致性约束是这类模型进入电力与算力场景的前提——99.5%的物理一致率意味着模型给出的调度建议在99.5%的情况下与真实物理规律相符，这是可以直接下发到设备执行而不需要二次校验的水平。

## 四、AIDC 与中国储能产业链的连接点

| 环节 | 已有基础 |
|------|----------|
| **系统集成** | 海博思创获国内政策与订单双支撑（钠电+算电协同） |
| **电芯供应** | 宁德时代、亿纬锂能、鹏辉能源受益于全球动储一体化放量 |
| **PCS/逆变器** | 阳光电源依托大储出海优势及 AIDC 电源布局；德业股份工商业储能逆变器毛利率维持 58% |
| **出口通道** | 2026年1—8月逆变器出口额 526 亿元，同比 **+22%**；8月出口量 493.6万台，同比 **+20.35%** |

阳光电源 9月15日与马来西亚 ERS Energy 达成合作，在马来西亚与菲律宾落地总规模 **1GWh** 储能项目，被机构研报明确归入"AIDC电源布局"的受益标的序列。

## 五、风险与不确定性

| 风险 | 说明 |
|------|------|
| **订单落地节奏** | 框架协议不等于实际交付，2027年16GWh的可执行性需持续跟踪 |
| **海外政策壁垒** | 美国 IRA 税收抵免 30% 但本土化率要求、UFLPA 溯源严格，长协需配套本地化产能 |
| **AIDC 负荷波动** | 大模型训练负载波动大，储能配置容量存在优化风险 |
| **国内机制尚未建立** | AIDC 储能尚未获得国内容量电价/需求响应等机制的明确覆盖，收益模型依赖企业与电网双边协商 |
| **技术路线未定型** | 锂电、钠电、燃料电池在AIDC 场景的竞争格局尚未形成 |

---

## 六、结论

> AIDC 储能的真正价值在于**它是储能行业第一个由企业自有资本支付、而非依赖政策机制的需求增量**。Fluence 的 206GWh 框架协议、阳光电源的马来/菲律宾 1GWh 订单，都指向同一个判断：算力基础设施正在成为继新能源之后第二个确定的储能需求源。但需要注意区分"订单"与"需求"——框架协议只证明了买方的规划意愿，真正的验证要等到2027年16GWh的实际交付。从国内视角看，AIDC 储能尚未进入容量电价等机制覆盖范围，收益模型仍需双边协商确定，这是与独立储能最大的制度差异。
